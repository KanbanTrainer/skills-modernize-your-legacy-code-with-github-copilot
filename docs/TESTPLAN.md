# COBOL Account Management Test Plan

Use this plan to validate the current COBOL behavior with business stakeholders and as a starting point for Node.js unit and integration tests. Start a fresh application process where a case says to do so. Record observed output in **Actual Result**, then set **Status (Pass/Fail)** after comparing it with the expected result. Cases marked for stakeholder confirmation describe behavior that the COBOL source does not define safely or explicitly.
